Cord runs AI coding agents in cloud sandboxes connected to your GitHub repos. Each session gets a branch, a full dev environment, and an agent that writes code and opens PRs.

## How it works

<Steps>
  <Step title="Connect your org and repos">
    Sign in with GitHub and add your organization. Repos, credentials, MCP servers, and integrations are configured at the org level.
  </Step>
  <Step title="Add your AI provider">
    Connect a Claude or Codex subscription, add API keys, or claim **\$100 in free credits** during onboarding.
  </Step>
  <Step title="Start a session">
    Start from the web app, Slack, Linear, the CLI, or your phone. Each session creates a branch and spins up a sandbox with your full stack running.
  </Step>
  <Step title="Review and merge">
    Review diffs, check the live preview, and merge the PR.
  </Step>
</Steps>

## What runs in a sandbox

- Your code cloned from GitHub with dependencies installed
- Dev server running on a unique preview URL
- Docker support
- Headless browser for visual verification
- Terminal accessible from the UI or via VS Code (code-server)

Sandboxes suspend when idle (no charge) and resume instantly.

## AI providers

| Method | Description |
|---|---|
| **Starter credit** | \$100 free AI credits for Claude and OpenAI with new accounts. |
| **Cord Open Source** | Free open-source models available to all accounts. |
| **Claude subscription** | Connect Claude Max/Pro via OAuth. Runs Claude Code. |
| **Codex subscription** | Connect ChatGPT Plus/Pro. Runs OpenCode. |
| **API keys** | Anthropic, OpenAI, Google, Mistral, DeepSeek, xAI, Groq, OpenRouter, Bedrock, and more. |

Admins can set org-level shared API keys. See [AI providers](/guides/ai-providers).

## Org structure

Repos, API keys, MCP servers, and integrations are configured at the org level. Every team member gets access without individual setup.

Roles: **Owner**, **Admin**, **Member**. Admins manage settings and integrations. Members start sessions.

## MCP servers and skills

Cord supports [MCP](https://modelcontextprotocol.io/) for connecting agents to external tools and data sources. Skills are instruction files that teach agents your coding patterns.

Both are scoped at three levels: org, repo, and user. See [MCP servers & skills](/guides/mcp-and-skills).
