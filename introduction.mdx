Cord gives your team cloud sandboxes for AI coding agents. Connect your GitHub repos, bring your AI subscription or API keys, and start shipping code from Slack, Linear, your laptop, or your phone.

Each session spins up a full dev environment -- your code, dependencies, dev server, Docker, a browser -- and an AI agent that reads your codebase, writes code, runs tests, and opens a PR.

## How it works

<Steps>
  <Step title="Connect your org and repos">
    Sign in with GitHub and add your organization. Cord is org-native -- repos, credentials, MCP servers, and integrations are configured once at the org level. Every team member gets access automatically.
  </Step>
  <Step title="Add your AI provider">
    Bring your Claude Max/Pro subscription, your Codex subscription, or raw API keys from 12+ providers. Don't have any? New accounts can claim **\$100 in free AI credits** during onboarding.
  </Step>
  <Step title="Start a session">
    Start from anywhere -- the web app, your phone, Slack, Linear, or the API. Each session creates a Git branch and spins up a cloud sandbox with your full stack running. Describe what you want in plain English (or record a voice message) and the agent writes the code.
  </Step>
  <Step title="Review, merge, repeat">
    Review diffs, check the live preview URL, and merge the PR -- all from Cord. Or skip the app entirely: tag `@Cord` in Slack or assign a Linear ticket, and a PR appears in GitHub.
  </Step>
</Steps>

## What runs in a sandbox

Every sandbox is a full dev environment, not a thin container:

- **Your code** cloned from GitHub with dependencies installed
- **Dev server** running on a unique preview URL you can share with your team
- **Docker** fully supported for projects that need it
- **Headless browser** for the agent to visually verify its own output
- **Terminal** accessible from the Cord UI or via VS Code (code-server)

Sandboxes spin up in seconds, suspend when idle (you're not charged), and resume instantly.

## Org-native by default

Cord is built for teams, not individuals bolting on collaboration. When an admin sets up Cord:

- **Repos** are added at the org level -- every member can start sessions on any connected repo
- **API keys** can be shared org-wide so individual devs don't need their own
- **MCP servers** are configured once by an admin and available to every session across the org
- **Integrations** (Slack, Linear) connect at the org level
- **Skills and config** propagate to every new sandbox automatically

Roles are simple: **Owner**, **Admin**, and **Member**. Admins manage org settings, repos, shared credentials, and integrations. Members start sessions and write code.

## MCP servers and skills

Cord supports the [Model Context Protocol](https://modelcontextprotocol.io/) (MCP) for giving agents access to external tools and data sources.

MCPs are scoped at three levels:
- **Org-level** -- configured by admins, available to every session in the org
- **Repo-level** -- specific to a repository
- **User-level** -- personal MCP servers for individual workflows

Skills (instruction files that teach agents your coding standards and patterns) work the same way -- configure once at the org level, and every agent session picks them up.

See [MCP servers & skills](/guides/mcp-and-skills) for configuration.
