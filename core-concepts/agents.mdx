Cord runs two agents. Both have full access to the sandbox filesystem, terminal, and browser.

## Claude Code

[Claude Code](https://docs.anthropic.com/en/docs/claude-code) is Anthropic's coding agent. Used with Claude subscriptions or Anthropic API keys. Supports extended thinking.

## OpenCode

[OpenCode](https://github.com/nicepkg/opencode) is an open-source coding agent. Used with Codex subscriptions, API keys from other providers, and Cord Open Source models.

Supported providers: OpenAI, Anthropic (via API), Google, Mistral, DeepSeek, xAI, Groq, OpenRouter, Amazon Bedrock, Cord Open Source.

## Capabilities

Both agents can:

- Read and write files
- Run commands (builds, tests, linters)
- Start dev servers
- Use a headless browser for visual verification
- Create PRs
- Call MCP tools

## Defaults

Configure in **Settings > Models & API Keys**:

- Default agent (Claude Code or OpenCode)
- Default model
- Thinking mode

Override per-repo in Repository Settings, or per-session with **Cmd+/**.

## Credential routing

When multiple providers are configured, routing priority:

1. Personal API keys
2. Personal subscriptions
3. Org-level shared keys

Customize priority order in **Settings > Models & API Keys**.

## Thinking mode

Extended thinking makes the agent spend more compute on reasoning before acting. Toggle in the model selector (**Cmd+Shift+/**) or set as default.
