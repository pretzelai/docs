---

A session ties together a Git branch, a cloud sandbox, and an AI agent.

## Branches

Each session creates a branch from your repo's default branch. All file changes happen on this branch.

## Starting sessions

- **Web UI** — click "New Session" on a repo
- **Slack** — tag `@Cord` with a task description
- **Linear** — assign a ticket to Cord
- **CLI** — `cord sessions create --repository my-org/app --message "..."`
- **API** — `POST /api/v1/sessions`
- **Push & Pull** — say "push to Cord" from your local agent
- **Mobile** — voice message

## Parallel sessions

Multiple sessions can run simultaneously on the same repo. Each gets its own branch and sandbox.

## Chat

### @ mentions

Type `@` to attach context: files, sessions, PRs, skills, MCP tools, or scratch pad notes.

### Attachments

Paste or drag-and-drop images, screenshots, mockups, error logs.

### Prompt history

**Up/Down** arrows navigate previous prompts.

### Queuing messages

You can queue a follow-up while the agent is still working.

## Slash commands

| Command | What it does |
|---|---|
| `/model` | Switch model or thinking level |
| `/voice` | Dictate a message |
| `/expand` | Show native terminal panels |
| `/repository` | Switch active repository |

## Quick actions

Buttons below the input:

- **Undo** / **Redo** — rewind or restore the agent's last step
- **Compact** — summarize conversation to reclaim context
- **Review** — agent self-reviews its changes

## Build mode vs Plan mode

**Shift+Tab** toggles:

- **Build** (default) — reads, writes, and runs code
- **Plan** — analyzes and plans without making changes

## Scratch pad

**Alt+S** opens a notes area. Reference with `@scratch pad`.

## Forking

Fork a session at any message to create a child session with the same state.

## Context capacity

The ring in the input shows context usage. Use **Compact** when it fills up.

## Stopping

**Escape** once for warning, again to stop. Changes are preserved.

## Continuing

- Send follow-up instructions on the same branch
- **Keep Working** after merge to start a new session with previous context
- Fork from any point

Also via CLI: `cord sessions send <id> --message "..."`.

## Lifecycle

1. **Running** — agent working
2. **Ready** — waiting for review
3. **PR open** — pull request created
4. **Merged** — PR merged
5. **Archived** — no longer active
