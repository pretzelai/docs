---
title: "Persistent storage"
description: "Files and config that persist across sandbox sessions."
---

Persistent storage holds files that should be available in future sandboxes but don't belong in the repo. Per-user, not per-repo.

## What persists

- `.claude/` and `.agents/` directories (skills, config)
- Dotfiles (`.bashrc`, `.gitconfig`)
- Project config, templates, scripts
- Secret files you don't want in your repo

## Uploading

In **Settings > Persistent Storage**: upload files/folders, set a mount path, choose scope (all repos or specific repo), and toggle auto-mount.

| File | Mount path | Result |
|---|---|---|
| `.bashrc` | `~/.bashrc` | Replaces sandbox `.bashrc` |
| `claude/` | `/repo/.claude` | Claude config at repo root |
| `.env.local` | `/repo/.env.local` | Env file in project |

## Syncing local skills

```bash
cord storage sync-skills
```

Uploads `~/.claude/skills` and `~/.agents/skills` and auto-mounts them. Run again when you update local skills.

## CLI upload

```bash
cord storage upload ~/.bashrc --mount-path "~/.bashrc"
cord storage upload ./my-config --mount-path "/repo/.config" --name "project config"
cord storage upload .env.local --mount-path "/repo/.env.local" --repo-id repo_abc123 --include-sensitive
```

Skips secrets by default (`.env`, `*.key`, `*.pem`, `.aws/`, `.ssh/`). Use `--include-sensitive` to override. Limits: 5,000 files, 200 MiB per file, 1 GiB total.

See [CLI reference](/reference/cli#storage-upload) for all flags.
