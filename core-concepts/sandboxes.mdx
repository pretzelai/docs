Each session gets an isolated sandbox with your code, dependencies, and dev server running.

## Contents

- Repository clone at latest commit
- Dependencies installed
- Environment variables from repo settings
- Docker support
- Dev server on a unique preview URL
- Headless browser

## Lifecycle

- **Spin-up** — seconds. Code checked out, dependencies installed, dev server started.
- **Active** — agent can read/write files, run commands, start servers, use the browser.
- **Suspend** — automatic on idle. No charge.
- **Resume** — instant. File changes and state preserved.

## Preview URLs

Each sandbox has a unique URL for its dev server. Open it to see changes, share with teammates, or let the agent verify visually.

## Compute

Billed by the hour, only while active. See [Usage](/billing/usage).
