---
title: "Slack"
description: "Start agents from Slack by tagging @Cord."
---

## Setup

1. **Settings > Slack > Connect Slack**
2. Authorize the Cord app

Cord appears as `@Cord` in your workspace.

## Team mapping

Auto-maps members by matching email addresses. Click **Re-sync Members** if mappings get stale.

## Usage

```
@Cord Add rate limiting to the /api/auth endpoints.
Use express-rate-limit, 100 requests per 15 minutes per IP.
```

Cord routes to the right repo, starts an agent, posts updates in a thread, and shares the PR link when done.

Be explicit about the repo if routing is ambiguous:

```
@Cord In the frontend repo, fix the broken dropdown on the settings page.
```

## Images

Paste or upload images in your message. The agent receives them as context.

## Thread replies

Reply with `@Cord` in a thread to send follow-up instructions to the agent. Other team members can do the same.

## Slack memory

Per-user memory that persists across sessions. Admins enable in **Settings > Slack > Enable Slack Memory**. Users edit theirs in **Settings > Slack > Personal Slack Memory**.

## System prompt

Admins can set a custom system prompt for all Slack-triggered sessions in **Settings > Slack > Slack System Prompt**.

## Auto-provisioning

**Settings > Slack > Auto-provision** — automatically creates Cord accounts for Slack users who tag `@Cord` for the first time.

## File sharing

Agents can post files (logs, screenshots, build output) back to the Slack thread. Files you upload are passed to the agent as context.

## Notifications

When done, Cord posts a summary, PR link, and session link in the thread.
