## Setup

1. **Settings > Linear > Connect Linear**
2. Authorize the Cord app

## Team mapping

Auto-maps by email. Click **Re-sync Members** if mappings get stale. Members can also link their personal Linear account in settings.

## Usage

Assign a Linear issue to **Cord**. It reads the issue, routes to the right repo, starts an agent, and links the PR when done.

Write tickets that are specific, self-contained, and scoped to one deliverable. Include code references and acceptance criteria — the agent reads everything.

## Repo routing

Cord routes based on ticket description, labels, previous patterns, and Linear project/team associations. Be explicit if ambiguous.

## Status updates

| Event | Linear status |
|---|---|
| Agent starts | **In Progress** |
| Progress | Comments on issue |
| PR created | PR linked |
| PR merged | **Done** |

## Disconnecting

Admins disconnect in **Settings > Linear**. Members can unlink personal accounts independently.
