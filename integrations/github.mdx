## Connecting repositories

Cord uses a **GitHub App** for repo access. In **Settings > GitHub**:

1. Click **Add Organization** (or **Add Personal**)
2. Select repos in GitHub's install flow
3. Redirected back to Cord

Multiple installations supported (one per org plus personal). Org admin may need to approve.

## PR attribution

PRs default to Cord's bot account. To use your name/avatar: **Settings > GitHub > Pull Request Attribution > Link GitHub Account**.

## Collaborator access

For repos where you're a collaborator but the owner hasn't installed the Cord GitHub App: use **Collaborator Repository Access** (classic OAuth) in **Settings > GitHub**.

## Organization rules

Admins see **Organization Rules** in **Settings > GitHub**:

| Rule | What it does |
|---|---|
| **Allow personal repository installs** | Members can connect personal repos |
| **Require each person to link GitHub** | Blocks PR operations until linked |
| **Only admins can add org installs** | Restricts app installation |

## Branch naming

Always `cord/` prefix:

- Before first commit: `cord/adjective-animal-e7b7`
- After first commit: `cord/descriptive-slug-a1b2c3`

## CI/CD

Standard GitHub PRs. Existing pipelines, status checks, and branch protection work normally.

## Quick PR and YOLO visibility

Toggle off in **Settings > UI Preferences > Thread Shortcut Settings** if you don't use them.
