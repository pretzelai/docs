## Keyboard shortcuts

### Global

| Shortcut | Action |
|---|---|
| **Cmd+K** | Open command palette |
| **Cmd+B** | Toggle left sidebar |
| **Alt+S** | Toggle scratch pad |
| **Alt+N** | New thread launcher |
| **?** | Open shortcut reference |

### Session

| Shortcut | Action |
|---|---|
| **Cmd+/** | Open model selector |
| **Cmd+Shift+/** | Cycle thinking effort level |
| **Shift+Tab** | Toggle Build/Plan mode |
| **Cmd+L** | Focus composer |
| **Cmd+P** | Go to file |
| **Cmd+Shift+P** | Toggle preview |
| **Cmd+Shift+L** | Toggle dev logs |
| **Cmd+Shift+R** | Reload preview |
| **Cmd+Shift+E** | Show files panel |
| **Cmd+Shift+G** | Show changes panel |
| **Cmd+Alt+B** | Toggle file explorer (right panel) |
| **Ctrl+`** | Toggle terminal |
| **Ctrl+Shift+`** | New terminal tab |

### Composer

| Shortcut | Action |
|---|---|
| **Enter** | Send message |
| **Shift+Enter** | Insert newline |
| **Cmd+G** | Stop current agent run |
| **Up/Down** | Navigate prompt history |
| **Escape** (press twice) | Stop the running agent |

### Files

| Shortcut | Action |
|---|---|
| **Cmd+F** | Find in file |
| **Cmd+W** | Close tab |
| **Cmd+Shift+]** | Next file tab |
| **Cmd+Shift+[** | Previous file tab |

### Git

| Shortcut | Action |
|---|---|
| **Cmd+Enter** | Commit |
| **Cmd+Shift+Enter** | Commit and push |

On Windows/Linux, substitute **Ctrl** for **Cmd**.

## Command palette

Press **Cmd+K** to open the command palette. From here you can:

- Navigate to any settings page
- Switch to a different session
- Open a repository
- Create a new session
- Toggle UI panels (sidebar, file explorer, terminal, scratch pad)
- Jump to repo setup pages

The command palette searches across all your repos, sessions, and settings.

## UI preferences

Customize the interface in **Settings > UI Preferences**:

### Display options

| Setting | Description |
|---|---|
| **Show timestamps** | Display timestamps on chat messages |
| **Show Recents in sidebar** | Show recently visited sessions at the top of the sidebar |
| **Show Team threads in sidebar** | Show sessions from other team members |
| **1-click delete for threads** | Show a delete button directly on sidebar threads (instead of requiring a menu) |
| **Autosend after voice dictation** | Automatically send the transcribed message after voice recording finishes |

### Terminal settings

Customize the integrated terminal:

| Setting | Options |
|---|---|
| **Theme** | Multiple color themes with preview swatches |
| **Font family** | Geist Mono, JetBrains Mono, System Monospace |
| **Font size** | 12, 13, 14, 16 |
| **Line height** | Compact, Default, Relaxed |
