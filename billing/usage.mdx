## Sandbox hours

One sandbox hour = one hour of active compute time.

**Counts:** Active sandbox time (agent working, dev server running, you browsing preview), startup time.

**Doesn't count:** Idle/suspended time, resume time, Cord UI usage (browsing sessions, reviewing diffs).

## Suspension

Sandboxes suspend automatically after idle time. No charge while suspended. State is preserved. Resumes instantly.

Shown in the dashboard if enabled for your workspace. Otherwise contact support.
