## Data handling

Code stays in your sandbox and GitHub. Cord doesn't store source code in its database — sandboxes are ephemeral and push back to GitHub.

## Credentials

- API keys encrypted at rest, injected into sandboxes at startup, never logged
- Subscription credentials stored encrypted, injected as needed

## Sandbox isolation

- **gVisor** — kernel-level isolation (same as Google Cloud Run)
- Separate filesystem per sandbox
- Network isolation between sandboxes
- Ephemeral — destroyed after use

## Environment variables

Encrypted at rest, decrypted only at startup, write-only in the UI.

## Authentication

GitHub, Google, and/or email sign-in. Session tokens managed by Better Auth with automatic expiry.

## Infrastructure

| Component | Provider |
|---|---|
| Sandboxes | Modal / Daytona / Freestyle |
| Database | Neon (Postgres) |
| Session coordination | Cloudflare Durable Objects |
| File storage | Cloudflare R2 |

## Enterprise

Run Cord on your own infrastructure: sandboxes in your cloud, no code leaves your network, SSO.
