## Data handling

Your code stays in your sandbox and your GitHub repository. Cord doesn't store your source code in its own database -- sandboxes are ephemeral compute environments that are created from and push back to GitHub.

## Bring your own keys (BYOK)

Cord receives provider credentials when you add them in Settings or connect a subscription, stores them securely, and injects the selected credential into sandboxes when needed:

- API keys are encrypted at rest
- Keys are injected into the sandbox at startup and exist only in memory
- Keys are never logged or stored in plaintext

For subscription-based access (Claude Max/Pro, Codex), Cord stores the connected subscription credential set encrypted and injects the necessary credentials into sandboxes for the selected agent.

## Sandbox isolation

Each sandbox is an isolated container with:

- **gVisor** -- application kernel-level isolation (the same technology Google Cloud Run uses)
- **Separate filesystem** -- no shared state between sandboxes
- **Network isolation** -- sandboxes can't access each other
- **Ephemeral by default** -- sandboxes are destroyed after use, no lingering state

## Environment variables

Environment variables you set in Cord are:

- Encrypted at rest in the database
- Decrypted only at sandbox startup
- Available only inside your sandbox
- Never exposed in the Cord UI after being set (write-only)

## Authentication

- **Sign-in methods** -- Cord supports configured sign-in methods such as GitHub, Google, and/or email.
- **Session tokens** -- managed by Better Auth, stored encrypted, with automatic expiry.
- **Passwords** -- password-based sign-in, if enabled, stores password hashes rather than plaintext passwords.

## Infrastructure

| Component | Provider | Location |
|---|---|---|
| Sandboxes | Modal / Daytona / Freestyle, depending on deployment | US / EU regions |
| Database | Neon (Postgres) | US |
| Session coordination | Cloudflare Durable Objects | Edge (global) |
| File storage | Cloudflare R2 | US |

## Enterprise

On the Enterprise plan, you can run Cord on your own infrastructure. This means:

- Sandboxes run in your cloud account
- No code leaves your network
- Full control over data residency
- SSO with your identity provider
