## 1. Sign in with GitHub

Go to [runcord.com](https://runcord.com) and sign in with your GitHub account. Cord uses GitHub OAuth -- no separate account to create.

If you're the first person from your team, Cord creates an organization for you automatically. You can invite teammates later in [Org setup](/guides/org-setup).

## 2. Set up your AI provider

Before you can start a session, you need an AI provider. Go to **Settings > Models & API Keys**.

<Tabs>
  <Tab title="Free open source models (fastest start)">
    Select **Cord Open Source** as your provider. This gives you access to models like **Kimi K2.6**, **Qwen 3.6 Plus**, **GLM 5.1**, and **MiniMax M2.7** at no cost. No API key needed.
  </Tab>
  <Tab title="Starter credit">
    Claim your **$100 starter credit** (available to every new account). This gives you $50 in Claude credits and $50 in OpenAI credits to try both agents without entering any payment info.
  </Tab>
  <Tab title="Claude subscription">
    If you have a Claude Max or Pro subscription, connect it via **Settings > Models & API Keys > Connect Claude**. This lets you run Claude Code directly with your existing plan.
  </Tab>
  <Tab title="Codex / ChatGPT subscription">
    If you have a ChatGPT Plus or Pro plan, connect it via **Settings > Models & API Keys > Connect ChatGPT**. This enables OpenCode with your Codex subscription.
  </Tab>
  <Tab title="API keys">
    Add API keys from any supported provider: Anthropic, OpenAI, Google, Mistral, DeepSeek, xAI, Groq, OpenRouter, or Amazon Bedrock. Paste your key in **Settings > Models & API Keys**.
  </Tab>
</Tabs>

<Tip>
**For team admins:** You can set org-level shared API keys in **Settings > Organization** so your whole team uses the same provider without each person configuring their own. See [Org setup](/guides/org-setup).
</Tip>

## 3. Add a repository

Click **Add Repository** and select a repo from your GitHub account or organization.

Cord auto-detects your build setup -- package manager, framework, build commands, and dev server port. Review and customize in **Repository Settings** if needed.

**Environment variables:** If your project needs them, add them in **Repository Settings > Environment Variables**. They're encrypted at rest and injected into every sandbox automatically.

**Docker:** If your project uses Docker, it works out of the box. Docker is available in every sandbox by default.

## 4. Start your first session

Click **New Session** on your repository. Each session creates:

- A fresh **Git branch** from your default branch
- A full **cloud sandbox** with your code, dependencies, and a running dev server
- An **AI coding agent** ready to take instructions

Pick your agent based on your provider:
- **Claude Code** -- if you connected a Claude subscription or have an Anthropic API key
- **OpenCode** -- if you connected a Codex subscription, have an OpenAI key, or are using free open source models

## 5. Give the agent a task

Type your request in natural language:

```
Add a GET /api/health endpoint that returns { "status": "ok", "timestamp": Date.now() }.
Include a test for the new endpoint.
```

Watch the agent work in real-time:
- **Chat** -- the agent's reasoning and progress
- **Changes** -- files being modified with live diff counts
- **Terminal** -- command output from builds and tests
- **Preview** -- your dev server running at a unique URL

## 6. Review and create a PR

Once the agent finishes:

1. **Review the diff** in the Changes panel
2. **Check the live preview** -- click the preview URL to see your running app with the changes applied
3. **Create a PR** -- click the button, and a pull request opens on GitHub

Your existing CI/CD, branch protection rules, and code review workflows all work as normal -- it's a standard GitHub PR.
