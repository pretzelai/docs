The onboarding wizard walks you through setup. Here's what each step does.

## 1. Create your account

Go to [runcord.com](https://runcord.com) and sign up with GitHub, Google, or email/password. A workspace is created automatically.

## 2. Connect a model provider

You need an AI provider before you can start a session.

<Tabs>
  <Tab title="Starter credit (recommended)">
    Claim **\$100 in free credits** for Claude and OpenAI. No credit card needed.
  </Tab>
  <Tab title="API key">
    Select a provider and paste your API key. Expand **Advanced options** for custom base URLs.
  </Tab>
  <Tab title="Claude subscription">
    Install the CLI, run `cord auth login` and `cord providers connect claude`. Uses browser OAuth by default.
  </Tab>
  <Tab title="ChatGPT / Codex subscription">
    Click **Start device authorization**, get a one-time code, enter it on the OpenAI page.
  </Tab>
</Tabs>

Admins can set org-level shared API keys in **Settings > Organization** so the team doesn't need individual keys. See [Org setup](/guides/org-setup).

## 3. Connect GitHub

Click **Connect GitHub** to install the Cord GitHub App and select which repos to grant access to.

## 4. Pick a repository

Select a repo from your GitHub App installation.

## 5. Configure your repo

<Steps>
  <Step title="Build config">
    Choose **Set up automatically** (Cord inspects your repo and proposes config) or **Set up manually**.
  </Step>
  <Step title="Environment variables">
    Add secret files your project needs (encrypted, injected into sandboxes). Skip if not needed.
  </Step>
  <Step title="Prebuilt image (optional)">
    Build a Docker image with dependencies pre-installed for faster sandbox startup.
  </Step>
</Steps>

## 6. Start a session

Click **New Session**, type your request:

```
Add a GET /api/health endpoint that returns { "status": "ok", "timestamp": Date.now() }.
Include a test.
```

The workspace shows:
- **Chat** — agent reasoning and progress
- **Changes** — modified files with diffs
- **Terminal** — command output
- **Preview** — dev server at a unique URL

## 7. Create a PR

Review the diff in the Changes panel, check the preview, then click **Quick PR** to open a pull request on GitHub.
