## 1. Sign in with GitHub

Go to [runcord.com](https://runcord.com) and sign in with your GitHub account. Cord uses GitHub OAuth -- no separate account to create.

## 2. Add a repository

After signing in, click **Add Repository** and select a repo from your GitHub account or organization.

Cord will automatically detect your project's build setup (package manager, framework, build commands). You can review and customize this in repository settings.

<Tip>
If your project needs environment variables, add them in **Repository Settings**. They're stored encrypted and injected into every sandbox automatically.
</Tip>

## 3. Start your first session

Click **New Session** on your repository. Each session creates:

- A fresh Git branch
- A full cloud sandbox with your code, dependencies, and dev tools
- An AI coding agent ready to work

Choose your agent:
- **Claude Code** -- use with your Claude Max/Pro subscription or an Anthropic API key
- **OpenCode** -- works with any model provider, including OpenAI Codex subscriptions

## 4. Give the agent a task

Type your request in natural language. For example:

```
Add a /health endpoint that returns { "status": "ok" } with the current timestamp.
```

The agent will:
1. Read your codebase to understand the structure
2. Write the code
3. Run any relevant tests
4. Show you the diff

## 5. Review and create a PR

Once the agent is done:

1. Review the changes in the **Changes** panel on the right
2. Optionally check the **live preview URL** if your project runs a dev server
3. Click **Create PR** to open a pull request on GitHub

That's it. Your first AI-generated PR is ready for review.
