One-Shot is at [oneshot.runcord.com](https://oneshot.runcord.com). Submit a prompt, close the tab, get a PR via email.

## How it works

1. Sign in
2. Pick a repo
3. Write your prompt
4. Attach files if helpful (screenshots, mockups, specs)
5. Submit

Cord runs the agent, opens a PR, and emails you links to the PR and session.

## When to use it

Tasks where you can describe the full requirement upfront: bug fixes, new endpoints, refactoring, tests, docs. For back-and-forth work, use a normal session.

## Attachments

Drag-and-drop or paste screenshots, mockups, error logs, specs.

## Send another

Click **Send another prompt** after submitting. Remembers your last repo and model.
