One-Shot is a stripped-down interface for fire-and-forget tasks. Describe what you want, walk away, get a PR via email.

Go to [oneshot.runcord.com](https://oneshot.runcord.com) to try it.

## How it works

1. Sign in with your Cord account
2. Pick a repo (or connect one during onboarding)
3. Write your prompt — describe the change you want
4. Attach files if helpful (screenshots, mockups, specs)
5. Submit

Cord spins up a session, runs the agent to completion, opens a PR, and emails you links to both the PR on GitHub and the Cord session.

Close the tab after submitting — no need to watch.

## When to use it

One-Shot works best when you can describe the full requirement upfront:

- Bug fixes with clear repro steps
- Adding a well-defined endpoint or component
- Refactoring with specific instructions
- Writing tests for existing code
- Documentation updates

For tasks that need back-and-forth, use a normal session instead.

## Attachments

Drag-and-drop, paste, or use the attachment icon. Screenshots, design mockups, error logs, and spec documents all work. They're sent directly to the agent as context.

## Voice input

Tap the microphone icon to dictate instead of typing.

## Send another

After submitting, click **Send another prompt** to queue the next task. One-Shot remembers your last-used repo and model, so repeat submissions are fast.
