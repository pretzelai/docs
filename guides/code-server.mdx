Every Cord sandbox includes [code-server](https://github.com/coder/code-server) — a VS Code instance running in the cloud. Use it when you need a full IDE: manual edits, interactive debugging, codebase exploration, or complex terminal work.

## Opening VS Code

Click the **VS Code** button in any active session. A new tab opens with code-server connected directly to your sandbox's filesystem.

Everything is shared — same files, terminals, running dev server, and Git branch. Changes you make are immediately visible to the agent, and vice versa.

## Connection

VS Code connects directly to the sandbox via a tunnel URL (not routed through Cord's servers), so latency is low and the experience feels like a local editor.

## Extensions

Install extensions through the extensions panel. They live in the sandbox and won't persist across sessions unless you add them to [persistent storage](/core-concepts/persistent-storage).
