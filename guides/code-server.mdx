---
title: "VS Code (code-server)"
description: "Browser-based VS Code connected to your sandbox."
---

Every sandbox includes [code-server](https://github.com/coder/code-server). Click **VS Code** in any active session to open it.

Same filesystem, terminals, dev server, and branch as the agent. Changes are shared in both directions.

Connects directly to the sandbox via tunnel URL (low latency). Extensions don't persist across sessions unless added to [persistent storage](/core-concepts/persistent-storage).
