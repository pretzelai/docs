## Quick PR

Click **Quick PR** in the session header. Cord stages, commits, pushes, and opens the PR on GitHub with a generated title and description.

The button appears when your session has uncommitted changes or commits ready to push. The commit message, PR title, and description are generated from the diff, conversation, and recent commit history.

If a PR already exists on the branch, Quick PR pushes new commits to it instead of creating a duplicate.

## Customizing the PR

Click the **dropdown caret** next to Quick PR to open a form where you can set the title, description, and draft status. **Auto-fill with AI** generates a description you can edit.

Form inputs persist if you close and reopen the popover.

## YOLO

**YOLO** creates a PR, merges it, and archives the session in one action.

<Warning>
YOLO respects branch protection rules and required status checks. If CI fails, the merge won't go through.
</Warning>

## Reviewing changes

The **Changes** panel shows modified files with a diff view. Lines added are green, lines removed are red. Click collapsed indicators between hunks to expand context.

Check the live preview URL before merging if your project runs a dev server.

## Updating a PR

Send follow-up instructions after creating a PR — new commits push to the same branch and the PR updates automatically.

## Merging

Merge from Cord or from GitHub. If the base branch has diverged, ask the agent to rebase and fix conflicts.

## Keep working after merge

Click **Keep Working** to start a new session branching from the latest main with context from the previous session.
