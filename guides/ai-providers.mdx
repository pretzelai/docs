Cord is bring-your-own-AI. Connect your existing subscription, add API keys, or start with free credits — no credit card required.

## Starter credit

Every new account gets **$100 in free AI credits** for Claude and OpenAI. Claim it during onboarding or in **Settings > Models & API Keys**. This lets you try both Claude Code and Codex sessions before connecting your own subscription.

## Connect your Claude subscription

If you have a **Claude Max** or **Claude Pro** plan, connect it so Cord sessions use your existing subscription.

Install the CLI and log in:

```bash
curl -fsSL https://runcord.com/install.sh | bash
cord auth login
```

Then connect via browser OAuth:

```bash
cord providers connect claude
```

Approve the connection on Claude's OAuth page. Token refresh is automatic — you won't need to reconnect unless you revoke access.

Alternatively, connect via setup token if you prefer not to use browser OAuth:

```bash
cord providers connect claude --setup-token
```

If Claude Code is installed locally with an active subscription, the CLI auto-generates the token for you.

## Connect your ChatGPT subscription

If you have a **ChatGPT Plus** or **ChatGPT Pro** plan, connect it to use Codex-powered sessions.

First, enable device code authorization in your ChatGPT account at [chatgpt.com/#settings/Security](https://chatgpt.com/#settings/Security).

Then:

```bash
cord providers connect codex
```

The CLI shows a one-time code. Enter it on the OpenAI page to complete the connection.

## Disconnect

```bash
cord providers disconnect claude
cord providers disconnect codex
```

Or disconnect from the web app via the provider connection indicator in any session.

## Check status

```bash
cord providers list
```

Shows all connected providers and local CLI status.

## API keys

For pay-per-token pricing, add API keys in **Settings > Models & API Keys**. Supported providers:

| Provider | Notes |
|---|---|
| **Anthropic** | Claude models via API |
| **OpenAI** | GPT-4, o-series via API |
| **Google** | Gemini models |
| **Mistral** | Mistral models |
| **DeepSeek** | DeepSeek models |
| **xAI** | Grok models |
| **Groq** | Fast inference |
| **OpenRouter** | Multi-provider routing |
| **Amazon Bedrock** | AWS-hosted models |
| **Kimi** | Kimi models |

Keys are encrypted at rest and never logged.

Admins can add **shared API keys** at the org level (**Settings > Organization > Shared Provider API Keys**) so the whole team uses one billing account. Individual keys take priority over shared keys.

## Which agent runs with which provider?

| Provider | Agent |
|---|---|
| Claude subscription or Anthropic API key | **Claude Code** |
| ChatGPT subscription or OpenAI API key | **OpenCode** |
| All other providers | **OpenCode** |
| Cord Open Source (free) | **OpenCode** |

Switch providers per session with the model selector (**Cmd+/**).
