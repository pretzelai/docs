Cord is bring-your-own-AI. Connect your existing Claude or ChatGPT subscription, add API keys from any supported provider, or use free open source models. You can also get started immediately with [\$100 in free AI credits](#starter-credit) -- no credit card required.

## Connect your Claude subscription

If you have a **Claude Max** or **Claude Pro** plan from Anthropic, connect it to Cord using the CLI. This lets you run **Claude Code** sessions using your existing subscription -- Cord doesn't charge separately for AI usage.

### Prerequisites

1. **Install the Cord CLI** if you haven't already:
   ```bash
   curl -fsSL https://runcord.com/install.sh | bash
   ```

2. **Log in to Cord:**
   ```bash
   cord login
   ```

### Connect via browser OAuth (recommended)

The simplest way to connect. Run this command, and Cord opens your browser to authorize with Claude:

```bash
cord connect claude
```

You'll be taken to Claude's OAuth page. Approve the connection, and you're done:

```
Connected Claude
Stored your Claude subscription token in Cord.
```

This method automatically handles token refresh -- you won't need to reconnect unless you revoke access.

### Connect via setup token

If you prefer not to use browser OAuth, you can connect using a Claude setup token:

```bash
# If you have Claude Code installed locally with an active subscription,
# the CLI auto-generates the token for you:
cord connect claude --setup-token

# Or provide a token directly:
cord connect claude --token sk-ant-oat...
```

If Claude Code is installed and authenticated locally, the CLI detects it and offers to generate the token automatically. Otherwise it prompts you to paste one (run `claude setup-token` in another terminal to get it).

### Disconnect

```bash
cord disconnect claude
```

## Connect your ChatGPT subscription

If you have a **ChatGPT Plus** or **ChatGPT Pro** plan from OpenAI, connect it to use **Codex**-powered sessions.

### Prerequisites

Before connecting, enable device code authorization in your ChatGPT account:

1. Open [chatgpt.com/#settings/Security](https://chatgpt.com/#settings/Security)
2. Toggle ON: **"Enable device code authorization for Codex"**

### Connect

```bash
cord connect codex
```

The CLI shows a one-time code and opens your browser:

```
Your one-time code:  ABCD-1234
```

Enter the code on the OpenAI page, approve the connection, and the CLI confirms:

```
Codex connected successfully!
```

### Disconnect

```bash
cord disconnect codex
```

## API keys

If you prefer pay-per-token pricing, or want to use providers that don't have a subscription model, you can add API keys directly in **Settings > Models & API Keys**.

### Supported providers

| Provider | Notes |
|---|---|
| **Anthropic** | Claude models via API |
| **OpenAI** | GPT-4, o-series models via API |
| **Google** | Gemini models |
| **Mistral** | Mistral models |
| **DeepSeek** | DeepSeek models via API |
| **xAI** | Grok models |
| **Groq** | Fast inference |
| **OpenRouter** | Multi-provider routing |
| **Amazon Bedrock** | AWS-hosted models |
| **Kimi** | Kimi models via API |

Keys are encrypted at rest with AES-256-GCM and never logged.

### Org-level shared keys

Admins can add **shared API keys** at the org level so the whole team uses the same provider:

1. Go to **Settings > Organization**
2. Scroll to **Shared Provider API Keys**
3. Add keys for any provider

When a shared key is set, team members don't need their own keys for that provider. Individual keys take priority over shared keys if both exist.

## Which agent runs with which provider?

| Provider | Agent | Notes |
|---|---|---|
| Claude subscription | **Claude Code** | Uses your Anthropic subscription |
| Anthropic API key | **Claude Code** | Same agent, pay-per-token |
| Codex / ChatGPT subscription | **OpenCode** | Uses your OpenAI subscription |
| OpenAI API key | **OpenCode** | GPT-4 / o-series via API |
| All other providers | **OpenCode** | Works with any OpenAI-compatible API |
| Cord Open Source (free) | **OpenCode** | Free models, no key needed |

You can switch providers per session -- you're not locked into one.

## Starter credit

Every new account gets **\$100 in free AI credits** -- \$50 for Claude and \$50 for OpenAI. Claim it during onboarding or in **Settings > Models & API Keys**. No credit card required, credits don't expire.

This is the fastest way to try both Claude Code and Codex-powered sessions before connecting your own subscription.

## Free open source models

Every Cord account has access to open source models at no cost through the **Cord Open Source** provider. No API key needed -- enable it in **Settings > Models & API Keys** and start a session.

| Model | Best for |
|---|---|
| **Kimi K2.6** | General-purpose coding, default for new sessions |
| **Qwen 3.6 Plus** | Multi-language, large context |
| **GLM 5.1** | Strong general-purpose coding |
| **MiniMax M2.7** | Strong general-purpose coding |
| **DeepSeek V3.2** | Reasoning, code generation |
| **Gemma 4 31B** | Fast responses, lighter tasks |

All models support 128k context and tool calling. They run via the OpenCode agent inside your sandbox.
