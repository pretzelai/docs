## Starter credit

New accounts get **$100 in free AI credits** for Claude and OpenAI. Claim in onboarding or **Settings > Models & API Keys**.

## Connect Claude subscription

```bash
curl -fsSL https://runcord.com/install.sh | bash
cord auth login
cord providers connect claude
```

Uses browser OAuth by default. Token refresh is automatic.

To use setup-token instead:

```bash
cord providers connect claude --setup-token
```

## Connect ChatGPT subscription

Enable device code authorization at [chatgpt.com/#settings/Security](https://chatgpt.com/#settings/Security), then:

```bash
cord providers connect codex
```

Enter the one-time code on the OpenAI page.

## Disconnect

```bash
cord providers disconnect claude
cord providers disconnect codex
```

## Check status

```bash
cord providers list
```

## API keys

Add keys in **Settings > Models & API Keys**:

| Provider | Notes |
|---|---|
| **Anthropic** | Claude models via API |
| **OpenAI** | GPT-4, o-series via API |
| **Google** | Gemini models |
| **Mistral** | Mistral models |
| **DeepSeek** | DeepSeek models |
| **xAI** | Grok models |
| **Groq** | Fast inference |
| **OpenRouter** | Multi-provider routing |
| **Amazon Bedrock** | AWS-hosted models |
| **Kimi** | Kimi models |

Keys are encrypted at rest. Admins can add org-level shared keys in **Settings > Organization > Shared Provider API Keys**. Individual keys take priority.

## Provider → agent mapping

| Provider | Agent |
|---|---|
| Claude subscription or Anthropic API key | **Claude Code** |
| ChatGPT subscription or OpenAI API key | **OpenCode** |
| All other providers | **OpenCode** |
| Cord Open Source (free) | **OpenCode** |

Switch per session with **Cmd+/**.
