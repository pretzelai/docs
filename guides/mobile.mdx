Cord works as a Progressive Web App (PWA) on iOS and Android. Install it on your home screen for a native app experience.

## Installing the PWA

<Tabs>
  <Tab title="iOS (Safari)">
    1. Open [runcord.com](https://runcord.com) in Safari
    2. Tap the **Share** button (square with arrow)
    3. Scroll down and tap **Add to Home Screen**
    4. Tap **Add**
  </Tab>
  <Tab title="Android (Chrome)">
    1. Open [runcord.com](https://runcord.com) in Chrome
    2. Tap the **three-dot menu**
    3. Tap **Add to Home Screen** (or **Install app**)
    4. Tap **Install**
  </Tab>
</Tabs>

## Navigation

The mobile interface uses bottom sheet navigation:

- Tap a session to open it
- Switch between surfaces (chat, changes, terminal) using tabs
- Access quick actions via the menu icon

## Voice input

Tap the microphone icon in the composer to dictate your prompt. The screen stays awake during recording, and the transcribed text appears for review before sending.

In **Settings > UI Preferences**, toggle **Autosend after voice dictation** to skip the review step and send immediately.

Voice is great for kicking off agents on the go:

- *"Fix the broken login form — the submit button doesn't trigger validation"*
- *"Add a loading spinner to the dashboard while data is fetching"*

## Reviewing on mobile

The mobile interface is optimized for review:

- Session list with status indicators
- Diff view with syntax highlighting
- Chat for reading agent reasoning and sending follow-ups
- PR actions — Quick PR, Create PR, merge directly from your phone

## Starting agents from Slack

If you've set up the [Slack integration](/integrations/slack), you can start agents from your phone's Slack app. Tag Cord with a task description and the agent works in the background. You'll get a notification when it's done.
