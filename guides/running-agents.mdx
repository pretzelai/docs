## Starting a session

Pick a repo, type what you want. The agent starts immediately.

Switch models with **Cmd+/** or from the CLI:

```bash
cord sessions create --repository my-org/my-app \
  --message "Add a /health endpoint that returns status ok"
```

You can also hand off from a local agent with [Push & Pull](/guides/push-pull).

## Writing prompts

Be specific, reference files, describe what done looks like.

```
Add a GET /api/health endpoint to the Express server in src/server.ts
that returns { status: "ok", timestamp: Date.now() }
```

Type `@` to mention files, sessions, PRs, skills, or MCP tools as context.

## Attaching context

Paste, drag-and-drop, or use the file picker to attach screenshots, mockups, error logs, or documents.

## The workspace

- **Chat** — agent reasoning, tool calls, and questions
- **Changes** — modified files with diffs
- **Terminal** — command output (drag to resize)
- **Preview** — dev server at a unique URL

## Slash commands

Type `/` in the chat input:

| Command | What it does |
|---|---|
| `/model` | Switch model or thinking level |
| `/voice` | Dictate a message |
| `/expand` | Show native terminal panels for active sandboxes |
| `/repository` | Switch active repository for new sessions |

## Quick actions

Buttons below the chat input:

- **Undo** / **Redo** — rewind or restore the agent's last step
- **Compact** — summarize the conversation to reclaim context space
- **Review** — agent self-reviews its changes

## Build mode vs Plan mode

Toggle with **Shift+Tab**:

- **Build mode** (default) — reads, writes, and runs code
- **Plan mode** — analyzes and plans without making changes

## Scratch pad

**Alt+S** opens a notes area. Reference it later with `@notes`.

## Context capacity

The ring in the chat input shows context window usage. When it fills, use **Compact** or start a fresh session.

## Stopping the agent

**Escape** once shows a warning, **Escape** again stops. Changes are preserved.

## Iterating

Send follow-up instructions after the agent finishes. You can queue messages while the agent is still working.

## Voice input

Tap the mic icon or use `/voice` to dictate. Toggle **Autosend after voice dictation** in Settings to skip the review step.

## Notifications

Background sessions show a favicon indicator and send browser/push notifications when done.
