title: "Push & Pull"
description: "Say 'push to Cord' to hand off work to the cloud. Say 'pull from Cord' to get it back."
---

Push & Pull lets you hand off work between your local agent and Cord's cloud agents. Say "push to Cord" and your agent commits, writes a handoff, and sends it to the cloud. Say "pull from Cord" later and your agent retrieves what the cloud did, syncs the code, and continues.

Works with any agent that can run shell commands — Claude Code, Cursor, Codex CLI, Aider, Amp, or anything else.

<Info>
**Quick version:** Install the skill (`npx skills add pretzelai/cord-cloud-skill -g -y`), then tell your agent "push to Cord" or "pull from Cord". That's it.
</Info>

## Setup

### 1. Install the CLI

```bash
npm install -g cord-cli
cord auth login
```

`cord auth login` opens a browser for device auth. Sign in and approve.

### 2. Install the skill

```bash
npx skills add pretzelai/cord-cloud-skill -g -y
```

This drops the skill into your agent's skills directory. Manual alternatives:

| Agent | Path |
|---|---|
| Cursor / OpenCode | `.agents/skills/cord-push-pull/SKILL.md` |
| Claude Code | `.claude/skills/cord-push-pull/SKILL.md` |

Or just tell your agent: *"Install the cord push/pull skill from github.com/pretzelai/cord-cloud-skill"*.

## Pushing

When you want a cloud agent to take over — you're closing your laptop, the task is long-running, or you want to parallelize:

> "Push this to Cord and let it finish the API tests overnight"

Your agent commits, pushes, writes a structured handoff (what's done, current state, next steps), and calls `cord push`. Cord creates a session on your branch and starts working immediately.

You get a session URL you can check anytime, or forget about until morning.

---

## Pulling

When you want to retrieve what Cord did:

> "Pull from Cord"

Your agent calls `cord pull`, reads the handoff context, runs `git pull`, and continues where Cord left off. The cloud session is suspended so you're not charged while working locally.

If Cord is still mid-task, it tells you — try again later or open the link to watch progress.

### Pull works for any session

`cord pull` isn't just for sessions you pushed. It works with any Cord session on your branch — started from the web app, Slack, or Linear. Check out the branch and pull.

```bash
cord pull                              # auto-detects from current branch
cord pull --session session_abc123     # specific session
cord pull --branch feature/auth        # by branch name
```

---

## Checking status

```bash
cord status
```

Shows whether the session is running, idle, blocked, error, or suspended, with a link to the web UI.

## The loop

```
Monday evening:
  You: "Push this to Cord, have it finish the API routes"
  Agent: commits → pushes → handoff → cord push
  You: close laptop

Tuesday morning:
  You: "Pull from Cord, what did it do?"
  Agent: cord pull → git pull → continues working

Tuesday evening:
  You: "Push again, have Cord add the test suite"
```

Your local agent and Cord trade context back and forth, each picking up where the other left off.

## Manual CLI usage

Drive it yourself without going through an agent:

```bash
# Push with instructions
cord push --message "Finish implementing the pagination"

# Push with rich context
cord push --context "Rate limiting done. Need token refresh and tests." \
  --message "Implement token refresh"

# Push from a file
cord push --context-file ./HANDOFF.md --message "Continue this work"

# Resume a suspended session
cord push --session session_abc123 --message "I fixed the types, continue"
```

```bash
# Pull (auto-detects session from branch)
cord pull

# Save handoff to a file
cord pull --output ./handoff.md

# Keep cloud session running
cord pull --no-suspend
```

All commands support `--json` for scripting.

### Push flags

| Flag | Default | Description |
|---|---|---|
| `--message` | — | What the cloud agent should do |
| `--context` | — | Handoff context (inline) |
| `--context-file` | — | Handoff context (from file) |
| `--branch` | Current branch | Branch for the session |
| `--repository` | From git remote | GitHub repo (owner/name) |
| `--session` | — | Resume an existing session |
| `--model` | Your default | Override model |
| `--thinking` | — | Thinking/reasoning variant |

### Pull flags

| Flag | Default | Description |
|---|---|---|
| `--session` | — | Pull from a specific session |
| `--branch` | Current branch | Find session by branch |
| `--repository` | From git remote | Narrow lookup to a repo |
| `--output` | stdout | Save context to a file |
| `--no-suspend` | — | Keep cloud session running |

## Troubleshooting

| Error | Fix |
|---|---|
| `cord: command not found` | `npm install -g cord-cli` |
| `Not authenticated` | `cord auth login` |
| `Repository not accessible` | Install the Cord GitHub App (link in error message) |
| `No Cord session found for this branch` | Use `--session <id>` or `--branch <name>` |
| `Refusing to push base branch` | Create a feature branch first |
| Agent doesn't know push/pull | `npx skills add pretzelai/cord-cloud-skill -g -y` |
