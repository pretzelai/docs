title: "Push & Pull"
description: "Hand off work between your local agent and Cord's cloud agents."
---

Push & Pull lets you move work between your local agent and Cord. "Push to Cord" sends your work to the cloud. "Pull from Cord" retrieves what the cloud did.

Works with any agent that can run shell commands (Claude Code, Cursor, Codex CLI, Aider, Amp, etc.).

<Info>
Install the skill (`npx skills add pretzelai/cord-cloud-skill -g -y`), then tell your agent "push to Cord" or "pull from Cord".
</Info>

## Setup

### 1. Install the CLI

```bash
npm install -g cord-cli
cord auth login
```

### 2. Install the skill

```bash
npx skills add pretzelai/cord-cloud-skill -g -y
```

Manual alternative — place the skill file at:

| Agent | Path |
|---|---|
| Cursor / OpenCode | `.agents/skills/cord-push-pull/SKILL.md` |
| Claude Code | `.claude/skills/cord-push-pull/SKILL.md` |

---

## Pushing

Tell your agent something like "push this to Cord and finish the API tests." Your agent commits, writes a handoff, and calls `cord push`. Cord starts a session on your branch.

---

## Pulling

Tell your agent "pull from Cord." It calls `cord pull`, gets the handoff context, runs `git pull`, and continues where Cord left off. The cloud session suspends automatically.

`cord pull` works with any session on your branch — not just ones you pushed.

```bash
cord pull                              # auto-detects from current branch
cord pull --session session_abc123     # specific session
cord pull --branch feature/auth        # by branch name
```

## Checking status

```bash
cord status
```

## Manual CLI usage

```bash
cord push --message "Finish implementing the pagination"
cord push --context "Rate limiting done. Need token refresh." --message "Implement token refresh"
cord push --context-file ./HANDOFF.md --message "Continue this work"
cord push --session session_abc123 --message "I fixed the types, continue"
```

```bash
cord pull
cord pull --output ./handoff.md
cord pull --no-suspend
```

All commands support `--json`.

### Push flags

| Flag | Default | Description |
|---|---|---|
| `--message` | — | What the cloud agent should do |
| `--context` | — | Handoff context (inline) |
| `--context-file` | — | Handoff context (from file) |
| `--branch` | Current branch | Branch for the session |
| `--repository` | From git remote | GitHub repo (owner/name) |
| `--session` | — | Resume an existing session |
| `--model` | Your default | Override model |
| `--thinking` | — | Thinking/reasoning variant |

### Pull flags

| Flag | Default | Description |
|---|---|---|
| `--session` | — | Pull from a specific session |
| `--branch` | Current branch | Find session by branch |
| `--repository` | From git remote | Narrow lookup to a repo |
| `--output` | stdout | Save context to a file |
| `--no-suspend` | — | Keep cloud session running |

## Troubleshooting

| Error | Fix |
|---|---|
| `cord: command not found` | `npm install -g cord-cli` |
| `Not authenticated` | `cord auth login` |
| `Repository not accessible` | Install the Cord GitHub App (link in error message) |
| `No Cord session found for this branch` | Use `--session <id>` or `--branch <name>` |
| `Refusing to push base branch` | Create a feature branch first |
| Agent doesn't know push/pull | `npx skills add pretzelai/cord-cloud-skill -g -y` |
