Repos, API keys, MCP servers, and integrations are configured at the org level. Members get access without individual setup.

## Creating an org

Created during onboarding or in **Settings > Organization**.

## Inviting members

**Settings > Organization > Invite Member**. Enter email and assign a role. Members get immediate access to all connected repos and shared credentials.

## Roles

| Role | Can do |
|---|---|
| **Owner** | Everything — transfer ownership, delete org, promote roles |
| **Admin** | Manage repos, shared API keys, MCP servers, integrations, invite members |
| **Member** | Start sessions, write code, create PRs |

## Shared API keys

Admins set org-level keys in **Settings > Organization > Shared Provider API Keys**. Members use these by default; personal keys take priority if configured.

## Shared MCP servers and skills

Configure in **Settings > MCP & Skills**. Available in every session across the team. See [MCP servers & skills](/guides/mcp-and-skills).

## Integrations

- **Slack** — **Settings > Integrations > Connect Slack**
- **Linear** — **Settings > Integrations > Connect Linear**

See [Slack](/integrations/slack) and [Linear](/integrations/linear).

## Typical onboarding

1. Admin creates org and connects repos
2. Admin adds shared API keys
3. Admin configures MCP servers (if needed)
4. Admin connects Slack/Linear
5. Admin invites members
6. Members sign in and start working
