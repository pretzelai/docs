Cord is org-native. Repos, API keys, MCP servers, and integrations are set up once at the org level. Every team member gets access without configuring anything themselves.

## Creating an org

Create an organization during onboarding or in **Settings > Organization**. You can name it and customize the URL slug.

## Inviting team members

1. Go to **Settings > Organization**
2. Click **Invite Member**
3. Enter their email address and assign a role

Members sign in with their own account and immediately get access to all connected repos and shared credentials.

## Roles

| Role | Can do |
|---|---|
| **Owner** | Everything — transfer ownership, delete org, promote to admin/owner |
| **Admin** | Manage repos, shared API keys, MCP servers, integrations, invite members |
| **Member** | Start sessions, write code, create PRs. Uses org-configured resources. |

## Shared API keys

Instead of each developer adding their own AI provider keys, admins can set **org-level shared keys** in **Settings > Organization > Shared Provider API Keys**.

When a shared key exists, every team member can start sessions with that provider — no personal keys needed. If a member also has their own key for the same provider, their personal key takes priority.

## Shared MCP servers and skills

Admins can configure MCP servers and skills at the org level in **Settings > MCP & Skills**. These are available in every session across the team, appearing as read-only for non-admin members.

See [MCP servers & skills](/guides/mcp-and-skills) for details.

## Connecting integrations

Slack and Linear connect at the org level:

- **Slack** — go to **Settings > Integrations > Connect Slack**
- **Linear** — go to **Settings > Integrations > Connect Linear**

See [Slack](/integrations/slack) and [Linear](/integrations/linear) for detailed setup.

## Typical team onboarding

1. Admin signs in, creates an org
2. Admin connects repos the team works on
3. Admin adds shared API keys (or connects a Claude/Codex subscription)
4. Admin configures MCP servers if the team uses external tools
5. Admin connects Slack and/or Linear
6. Admin invites team members via email
7. Members sign in — everything is ready, they pick a repo and go
