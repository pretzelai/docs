---
title: "Global skills"
description: "Sync your local agent skills into Cord's cloud sandboxes."
---

If you've configured skills on your local machine (Claude Code's `~/.claude/skills/` or OpenCode's `~/.agents/skills/`), sync them into Cord so every cloud session picks them up.

## Syncing

```bash
cord storage sync-skills
```

This uploads your local skill directories to [persistent storage](/core-concepts/persistent-storage) and auto-mounts them at the same paths in new sandboxes. Run it again whenever you update your local skills.

Changes apply to new sandboxes, not already-running ones.

<Tip>
Repo-level `CLAUDE.md` and `.agents/` config files in your repository are also picked up automatically. Global skills and repo-level config work together — you don't have to choose one or the other.
</Tip>
