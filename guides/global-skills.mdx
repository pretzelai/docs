---
title: "Global skills"
description: "Syncing local agent skills into cloud sandboxes."
---

Sync local skills (`~/.claude/skills/` or `~/.agents/skills/`) into Cord:

```bash
cord storage sync-skills
```

Uploads to [persistent storage](/core-concepts/persistent-storage) and auto-mounts at the same paths. Run again when you update local skills. Applies to new sandboxes only.

Repo-level `CLAUDE.md` and `.agents/` files are picked up automatically alongside global skills.
