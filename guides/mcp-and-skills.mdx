## MCP servers

Cord supports [MCP](https://modelcontextprotocol.io/) for connecting agents to external tools and data sources.

### Adding an MCP server

In **Settings > MCP & Skills > MCP Servers**:

- Click **Add MCP Server** and enter URL + auth details, or
- Paste a JSON config block

Auth modes: **None**, **API key**, or **OAuth** (with automatic token refresh).

### Scoping

| Scope | Who configures | Who gets access |
|---|---|---|
| **Org-level** | Admins | Every session in the org |
| **User-level** | Individual users | Only their sessions |
| **Repo-level** | Repo settings | Sessions on that repo |

## Skills

Skills are instruction files that teach agents your coding patterns and conventions.

### Installing skills

- **From GitHub** — enter a repo URL and select skill files
- **From skills.sh** — browse community skills
- **Create inline** — write instructions in the Cord UI

### Scoping

| Scope | Description |
|---|---|
| **Org-level** | Team-wide standards. Every session reads them. |
| **Repo-level** | `CLAUDE.md` and `.agents/` files in your repo root. |
| **User-level** | Personal preferences. [Synced from local machine](/guides/global-skills) or added in settings. |

### Managing skills

View, edit, enable/disable, or delete in the Skills tab.
